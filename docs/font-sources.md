# Font sources

The title screen includes two fonts distributed through the official Google Fonts repository:

- **Vast Shadow Regular** - title wordmark. Copyright © 2011 Sorkin Type Co. Reserved Font Names “Vast” and “Vast Shadow.” Source: <https://github.com/google/fonts/tree/main/ofl/vastshadow>
- **Stardos Stencil Bold** - title subtitle. Copyright © 2011 Vernon Adams. Reserved Font Names “Stardos” and “Stardos Stencil.” Source: <https://github.com/google/fonts/tree/main/ofl/stardosstencil>

Both fonts are distributed under the SIL Open Font License 1.1. Copies of each font’s license are stored beside the corresponding font files under `public/assets/fonts/`.
